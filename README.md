# Анализ судебной практики — пошаговая инструкция (для нетехнаря)

## Простыми словами: что происходит

Робот (искусственный интеллект GitHub Copilot) читает решения судов и сам составляет по ним
аналитические разборы, таблицы и выводы. **Ваша задача — только запускать робота и вовремя
переключать модель** (два раза: сначала на дешёвую Luna 5.6, потом на умную Kimi K3).
Всё остальное он делает сам.


Работаем с **тремя судами**: `7кас`, `8кас`, `СОЮ Москвы и области`.
Остальные папки уже готовы — их **не трогаем**.

Вся работа идёт в **браузере**, на «облачном компьютере» (GitHub Codespaces).
На ваш компьютер ничего устанавливать не нужно.

---

## Что понадобится

1. Аккаунт на github.com.
2. Подписка GitHub Copilot Max (у вас есть).
3. Этот проект, загруженный на GitHub (Шаг 1 — делается один раз).

## ШАГ 1. Загрузить проект на GitHub (один раз)

### ✅ Вариант А — через программу GitHub Desktop (РЕКОМЕНДУЮ, без командной строки)

Этот способ **не требует командной строки и настройки** — имя, email и вход в аккаунт
программа берёт из вашего логина GitHub автоматически. Ошибок, как с `git config`, здесь не будет.

1. Скачайте и установите GitHub Desktop: https://desktop.github.com
2. Войдите в свой аккаунт GitHub в программе.
3. Меню **File → Add Local Repository** → выберите папку `legal-bro-p23`.
   - Если программа скажет «не найден репозиторий» — нажмите синюю ссылку **create a repository**.
4. Нажмите **Publish repository** (кнопка сверху).
   - Галочку **Keep this code private** оставьте включённой (проект приватный).
5. Готово — проект на GitHub. Переходите к Шагу 2.

### ⚙️ Вариант Б — через командную строку (если привыкли к терминалу)

**0. Сначала** создайте пустой репозиторий на github.com: кнопка **New repository** →
имя `legal-bro-p23` → **без** галочки «Add a README» → **Create**.

**1. Представьтесь git** (один раз; подставьте своё имя и email от аккаунта GitHub).
Без этого коммит упадёт с ошибкой `Author identity unknown`:

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш_email@example.com"
```

**2. Загрузите проект** (в ссылке замените `ВАШ_ЛОГИН` на ваш логин GitHub):

```bash
cd legal-bro-p23
git init
git add .
git commit -m "п.23: 7кас, 8кас, СОЮ Москвы"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/legal-bro-p23.git
git push -u origin main
```

> При `git push` может всплыть окно **входа в GitHub** — войдите в свой аккаунт.
> Если `git init` пишет «Reinitialized» — это нормально, просто репозиторий уже был создан.

## ШАГ 2. Открыть рабочее место (Codespace)

1. Откройте ваш репозиторий на github.com (страница проекта).
2. Нажмите зелёную кнопку **Code** (вверху справа).
3. Перейдите на вкладку **Codespaces**.
4. Нажмите **Create codespace on main**.
5. Подождите 1–2 минуты — в браузере откроется редактор (как VS Code).

> При первом запуске облачный компьютер собирается автоматически (это настроено в проекте).

---

## ШАГ 3. Запустить разметку (1 минута, робот НЕ нужен)

Разметка — это подготовка: обычный скрипт нарезает файлы на части.
**ИИ и контекст здесь не используются вообще** — можно запускать на все три суда сразу.

1. В Codespace откройте терминал: меню **Terminal → New Terminal** (вверху экрана).
2. Внизу появится окно с мигающим курсором. Введите команду и нажмите Enter:

   ```
   python markup.py
   ```

3. Дождитесь в терминале надписи:

   > **МУЖИК, ВКЛЮЧАЙ LUNA 5.6 — разметка готова**

Это сигнал: пора переключить модель на **Luna 5.6**.

---

## ШАГ 4. Черновой разбор (модель Luna 5.6 — дешёвая)

Теперь робот будет читать решения и делать черновики. Это **самая объёмная** часть,
поэтому используем **дешёвую** модель Luna 5.6 — она экономит ваши кредиты.

1. Откройте панель Copilot: нажмите **Ctrl+Alt+I** (или значок Copilot на боковой панели).
2. Внизу окна чата найдите **переключатель модели** (там написано имя текущей модели).
3. Выберите **Luna 5.6**.
4. В окне чата напишите команду и нажмите Enter:

   ```
   черновик 7кас
   ```

5. Робот начнёт заполнять файлы `дела_....md`. **Это долго** — суд из ~180 дел
   обрабатывается часами. Вкладку можно не закрывать, робот работает сам.
6. Когда робот закончит все группы суда, он напишет:

   > **ВКЛЮЧАЙ KIMI K3 — черновики готовы**

Это сигнал: пора переключить модель на **Kimi K3** для финальной части.

---

## ШАГ 5. Синтез (модель Kimi K3 — умная)

Черновики готовы. Теперь **дорогая, но умная** модель Kimi K3 проверит их и напишет
главный файл с выводами. Она работает недолго и читает только черновики, поэтому
кредитов уйдёт немного.

1. В переключателе модели выберите **Kimi K3** (режим **высокий effort / high**).
2. В окне чата напишите команду и нажмите Enter:

   ```
   синтез 7кас
   ```

3. Робот проверит черновики и создаст `итоговые_выводы.md` и сводные таблицы.

**Готово по суду 7кас!** Теперь повторите Шаги 4–5 для остальных судов:

- `черновик 8кас` (на Luna 5.6) → потом `синтез 8кас` (на Kimi K3)
- `черновик СОЮ` (на Luna 5.6) → потом `синтез СОЮ` (на Kimi K3)


---

## ⚠️ Если робот «завис», начал ошибаться или беседа оборвалась

Это **нормально**: у робота ограниченная «память» (контекст) на одну беседу.
**Прогресс не теряется** — он всё время сохраняется в файлы.

Что делать:

1. Откройте **новую беседу** (кнопка **+** в панели Copilot).
2. Напишите: `продолжи 7кас` (или 8кас / СОЮ).
3. Робот сам посмотрит, где остановился, и продолжит с нужного места.

> Совет: не пытайтесь впихнуть весь суд в одну беседу. Обработали несколько групп —
> робот подтормаживает? Открывайте новую беседу и пишите «продолжи …».

## Вопросы и ответы

**Хватит ли контекста?**
- Разметка (Шаг 3) — контекст **не нужен вообще**, это скрипт, а не ИИ.
- Анализ (Шаг 5) — одна группа дел влезает легко. Весь суд в одну беседу может не влезть —
  тогда см. раздел «Если робот завис». Прогресс сохраняется, ничего не потеряется.

**Нужно ли открывать файл AGENT_copilot.md?**
**Нет.** Это инструкция *для робота*, не для вас. Робот читает её сам автоматически
(это уже настроено). Вы только пишете в чат команды вроде «черновик 7кас».

**Что такое «черновик 7кас» и «синтез 7кас»?**
Просто команды для робота. «черновик 7кас» = «прочитай решения суда 7кас и сделай черновики»
(это делает дешёвая Luna 5.6). «синтез 7кас» = «проверь черновики и напиши итоговые выводы»
(это делает умная Kimi K3). Можно написать и по-человечески — робот поймёт.


**Робот написал что-то непонятное / спрашивает подтверждение?**
Если робот спрашивает разрешения запустить команду или прочитать файл — нажимайте **Allow / Разрешить**.
Это безопасно: он работает только внутри этого проекта.

**Сколько это стоит / не кончатся ли кредиты?**
Схема как раз придумана для экономии. Разметка — бесплатно (это скрипт, не ИИ).
Самую объёмную работу (чтение всех решений, ~2–3 МБ текста на суд) делает **дешёвая Luna 5.6**.
Дорогая Kimi K3 включается **только в конце** и читает не сырой текст, а готовые черновики —
поэтому её дорогих кредитов уходит немного. Это заметно дешевле, чем если бы Kimi читала всё.
